## 今回のMVP（この課題で作るもの）

1. ログイン（新規登録を含む）
2. タイムライン（「すべて」と「フォロー中」）
3. コメント（第三者が付けられる。件数を表示する）
4. いいね（第三者が付けられる。件数を表示する）
5. 画像投稿（本文に画像を1枚添えられる）
6. フォロー（他ユーザーのフォロー／解除。件数と一覧）
7. ユーザー検索（ユーザー名。結果・投稿・コメントからプロフィールへ進みフォロー）

利用者は **受講生または個人**。一人用ではなく、**複数ユーザーが同時に使う**前提。

## 初級編との位置づけ

初級編最終課題「おうち受付」は、受付担当と来客の **お問い合わせアプリ** だった。中級編は利用者同士が投稿し合う **SNS** に入る。認証・認可、N+1、テスト、ログ、CI/CD、AWS（無料枠）は実装フェーズで扱う。
